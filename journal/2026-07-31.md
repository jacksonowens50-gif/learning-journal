### Translate a SQL query into pandas — **read, not written**

I asked for this one instead of writing it. Being straight about the difference: I can read the translation and follow every line, but I did not prove I can produce it from a blank page. Marking it as passed would be lying to myself in a way that costs me in about three weeks.

The part worth retaining: **`WHERE` and `HAVING` are the same syntax in pandas and differ only in what they're applied to.** `WHERE` masks the DataFrame, `HAVING` masks the grouped result. SQL gives them separate keywords because SQL cares about execution order; in pandas the order is just the order I wrote the lines in, so the distinction shows up as *which variable I'm indexing*.

| SQL | pandas |
|---|---|
| `FROM` | `df` |
| `WHERE` | mask on `df` — before grouping |
| `GROUP BY a, b` | `.groupby(["a","b"])` |
| `SUM(x)` | `["x"].sum()` |
| `AS name` | `.rename(columns=...)` |
| `HAVING` | mask on **`grouped`** |
| `ORDER BY x DESC` | `.sort_values("x", ascending=False)` |
